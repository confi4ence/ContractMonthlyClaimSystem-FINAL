# ContractMonthlyClaimSystem-FINAL
A comprehensive WPF application for managing monthly claims submission, verification, and approval.

## 🎯 Features

### User Roles
- **Lecturers**: Submit claims and track status
- **Programme Coordinators**: Verify pending claims
- **Academic Managers**: Final approval of verified claims

### Key Functionalities
- ✅ Real-time claim submission with validation
- ✅ Secure document upload (PDF, DOCX, XLSX)
- ✅ Real-time status tracking with visual indicators
- ✅ Batch operations for coordinators
- ✅ Comprehensive error handling
- ✅ Unit testing coverage
